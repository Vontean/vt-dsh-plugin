## 1. 设计意图

| 项 | 判断 |
| --- | --- |
| 用户场景 | 用户在**读回答**，不是在使用一个应用。界面是回答的一部分，随时会被下一条消息顶走 |
| 界面寿命 | 秒级到分钟级：滚动过去就不再看，不复用、不导航 |
| 视觉基调 | **宿主正文的延伸**，不是嵌进来的独立产品。放松、低密、可略读 |
| 信息重心 | 内容 > 结构 > 装饰。装饰一旦需要被"看懂"，就是过度设计 |
| 成功判据 | 用户能在 2 秒内看出「这块在说什么」，并且不觉得文字被打断 |

三条铁律（改造与新建组件都受约束）：

1. **颜色只来自宿主 token**（`--dsw-alias-*` / `--dsw-static-*`），不自造品牌色、不硬编码 HEX。
2. **装饰密度低于正文**：同一屏里，强调只能靠**一个**手段（字号或颜色或留白），不能三样叠加。
3. **一个块只有一个焦点**：hero/stat 抢眼，其余组件必须退让；整块全是重点 = 没有重点。

## 2. 现状（上游 0.14.0，已验证）

### 2.1 Token 层

上游自建了 `--dsl-g-*` 前缀的 token 层，声明在 `.block, .panel` 上（hash 类名，构建后为 `.V1MMBW_block`）。
含义可参考，但**其取值正是我们要重做的部分**：

| 类别 | 现状取值 | 诊断 |
| --- | --- | --- |
| 字号 | mega 52 / stat-hero 44 / stat 34 / display 28 / h1 24 / h2 19 / h3 16 / body 14.5 / title 13.5 / meta 12.5 / data 12 | 11 档但都是非整数（14.5/13.5/12.5），与宿主 13/14 对不齐 |
| 字重 | 69 处声明，**67 处 ≥ 600**（正文 650、标题 800、标签 700） | 层级全靠字号硬撑，实际观感「通篇加粗」 |
| 间距 | 4 / 8 / 12 / 16 / 24 | 名义栅格成立，但有 30 处破格奇数值 |
| 圆角 | surface 12 / control 8 / pill 999 + 7 处字面值 | 三档之外还有散值 |
| 阴影 | 浅色 `0 1px 3px rgba(0,0,0,.10), 0 8px 24px rgba(0,0,0,.06)`；深色另一套 | 卡片同时有**边框 + 双层阴影**，深度语言重复 |
| 颜色 | `--dsl-g-accent: var(--dsw-alias-state-business-primary)` | **用状态色当品牌色**；宿主主色是 `--dsw-alias-brand-primary` |
| 主题 | 深浅色只靠 `body[data-ds-dark-theme]` + `--dsw-alias-*` | 方向正确，但只用了宿主 107 个 alias 里的 24 个 |
| 动效 | fast .15s / grow .6s / reveal .45s，一条 `cubic-bezier(.22,1,.36,1)` | 曲线统一是优点；逐项 90ms 级联在流式期间制造「迟到感」 |

### 2.2 表面语言（现状）

- 卡片：1px 边框 + 双层阴影 + 12px 圆角。
- 表头：全大写 + 字距 + 斑马行 + 上下双边框。
- hero：三层渐变底色。
- 进度条：渐变 + 高光。
- 图标：默认带色块底板。
- 组件入场：逐项 90ms 级联动画。

结论：**每个组件都在抢注意力**，叠加起来就是「AI 生成模板」的观感。

### 2.3 已知硬约束

| 约束 | 含义 |
| --- | --- |
| CSS 在构建期内联进 `lib/client.js`，类名 hash | 外部覆写 `--dsl-g-*` **无效**；改样式必须改源码重建 |
| 几何 token 宿主不提供 | 宿主只有 107 个颜色 alias + 5 个 `--ds-*`，间距/字号/圆角必须自建 → 自建就必须守住自己的栅格 |
| 深浅色必须两边都对 | 宿主浅色把 bg layer 映射成白色，深色是近黑；用「边框 + 阴影」还是「层差」必须分主题决定 |
| 必须支持 `prefers-reduced-motion` | 现状已遵守，不许回退 |
| 组件类名不对外承诺 | 只有 `[data-genui]` / `[data-genui-panel]` 是稳定属性 |

## 3. 改造方向（已定：宿主原生）

> 2026-11-01 确认。本章是实现判据：`src/client/**/*.module.css` 与组件 TSX 的每个视觉取值都应能回溯到这里。

**方向：宿主原生（host-native）** —— 放弃「第二套设计系统」，让 GenUI 看起来像宿主正文自己长出来的富文本，而不是嵌进来的仪表盘。代价是牺牲「惊艳」，换取「不打断阅读」。

判断顺序（冲突时按此仲裁）：

1. 这个视觉元素是否帮助理解内容？不帮助 → 去掉。
2. 它是否与宿主正文的排版冲突？冲突 → 服从宿主。
3. 它与同块内其它元素是否在抢同一个焦点？是 → 退让。

### 3.1 Token（第一版已落地）

Token 前缀沿用上游的 `--dsl-g-*`：换前缀会牵动 500+ 处引用，收益只有"看起来是我们的"，
不值得。数值是唯一权威来源，见 `src/client/GenuiBlock.module.css:42-70`；本表只解释语义。

| 角色 | token | 落地值 | 用途 |
| --- | --- | --- | --- |
| 正文 | `--dsl-g-font-body` | 14px / 400 | 段落型文本；与宿主正文同号 |
| 辅助 | `--dsl-g-font-meta` | 12px / 400~500 | 标签、单位、脚注、表头 |
| 次级文本 | `--dsl-g-font-title` | 13px / 400~500 | 表格正文、callout 正文、控件标签 |
| 小标题 | `--dsl-g-font-h3` | 15px / 600 | 卡片标题 |
| 章节标题 | `--dsl-g-font-h2` | 18px / 600 | divider 章节、hero 标题 |
| 页标题 | `--dsl-g-font-h1` | 24px / 600 | text.h1 |
| 大数字 | `--dsl-g-font-stat` | 28px / 600 | stat 数值 |
| 单点数字 | `--dsl-g-font-stat-hero` | 36px / 600 | stat.size=hero |
| 封面数字 | `--dsl-g-font-mega` | 40px / 600 | hero（一条回答最多一个） |
| 字重阶梯 | — | **400 / 500 / 600 三档** | 取消 650/680/700/750/800；强调只靠 600 |
| 间距 | `--dsl-g-gap-*` | 4 / 8 / 12 / 16 / 24 | 只允许这 5 个值 |
| 圆角 | `--dsl-g-radius-*` | 6 / 8 / 12 / 999 | 控件 8、容器 12、胶囊 999 |
| 描边 | `--dsl-g-border-surface` | `var(--dsl-g-border)` → 宿主 `--dsw-alias-border-l1`（浅 4% / 深 6%） | 只有容器有描边；**禁止用 label 色百分比自调**——12% 比宿主 hairline 深约 3 倍，就是「描边太粗、灰太重」的来源 |
| 斑马 / 隔行 | `--dsl-g-zebra` / `--dsl-g-zebra-head` | `--dsl-g-hover` 的 55% / 100%；深色改用 `bg-layer-2` 的 70% / 100% | 表格隔行底；表头比斑马高一档。来源是宿主交互填充 / 层台阶，不自调灰色 |
| 层级 | `--dsl-g-shadow-float` | 浅色 `0 4px 12px rgba(0,0,0,.10), 0 1px 2px rgba(0,0,0,.04)`；深色 `0 4px 16px rgba(0,0,0,.45)` | **只给真正浮起的元素**（tooltip、toast）。内联表面一律无阴影，描边与阴影永不叠加 |
| 强调色 | `--dsl-g-accent` | `var(--dsw-alias-state-business-primary)` | 暂沿用上游取值；改成 `brand-primary` 待独立验证后再动 |
| 语义底色 | `--dsl-g-tint` / `-quiet` / `-strong` | 12% / 8% / 14% | 语义表面用；不用于装饰 |
| 动效 | `--dsl-g-dur-*` / `-ease-out` | 0.15s / 0.45s / 0.6s，一条 deceleration 曲线 | 入场去掉逐项级联；流式期间不播放入场 |

### 3.2 组件规则（目标 / 进度）

| 组件 | 规则 |
| --- | --- |
| `card` | 只有「并排的多数据对象」才用卡；描边或阴影二选一；标题不加底色 |
| `table` | **保留斑马与行分隔线**（用户明确偏好）；表头保留原文大小写、不加字距；斑马底色由宿主填充 token 派生，表头比斑马高一档 |
| `list` | 项目符号用宿主正文的圆点，不另画竖线；条目间距 8，不画分隔线 |
| `progress` | 单位宽、无高光、无渐变；ring 只在 stat 组合里出现 |
| `hero` | 只在报告开场用；一层浅色底 + 一个大数字，不加渐变三层 |
| `stat` | 数字 28/600，label 12/400 muted；一屏最多 3 个 |
| `callout` | 只换左侧 3px 描边 + 8% 淡底，不加图标块 |
| `icon` | 默认无底板；只有显式 `tile` 才给底色 |
| `chart`/`plot` | 分类色板不再借用状态色；图表高度按容器自适应，不写死 160/300 |
