# DESIGN.md — dsh-vt-taskboard 视觉体系

> 状态：**已落地**（1.0.0）。本文是看板界面唯一的视觉约定；实现值在
> `src/client/styles.ts` 顶部的 `--vtb-*` 令牌层，本文解释语义与判据，不复制数值维护第二套定义。
> 截图见 [`img/board-light.png`](./img/board-light.png) 与 [`img/board-dark.png`](./img/board-dark.png)。

---

## 1. 设计意图

| 项 | 判断 |
| --- | --- |
| 入口 | 从 DSH 侧边栏点进来的一个面板，必须像 DSH 自带功能，而不是外挂皮肤 |
| 用户场景 | 每天盯盘：几十张卡在五列之间流转，读的是标题、状态、交付证据 |
| 视觉基调 | **跟随宿主**：白页面、极浅灰列、白卡片；颜色只留给语义 |
| 信息重心 | 标题 > 状态/进度 > 交付证据 > 次要元数据 |
| 成功判据 | 3 秒内能回答「哪张卡卡住了、哪张等我验收」，且长时间看不累 |

三条铁律：

1. **表面、文字、描边、强调色一律映射宿主令牌**（`--dsw-alias-*`），插件不自带底色。
2. **一个维度只有一个颜色信号**：紧急度里只有「紧急」有颜色，其余中性。
3. **动作与标签形态不同**：标签是软底填充，动作是描边按钮。

## 2. 令牌

### 2.1 宿主映射（明暗由宿主决定，插件不分组维护）

| 令牌 | 取值 | 用途 |
| --- | --- | --- |
| `--vtb-bg` | `transparent` | 由 DSH 页面底色透出（明亮主题为 `#fff`） |
| `--vtb-surface` | `--dsw-alias-bg-layer-2` → `bg-base` | 卡片、弹窗表面 |
| `--vtb-surface-2` | `墨色 4%` 混合 | 卡片内嵌块（交付概览、评论、执行记录） |
| `--vtb-overlay` | `--dsw-alias-bg-overlay` | 浮层 |
| `--vtb-ink / -2 / -3` | `--dsw-alias-label-primary/secondary/tertiary` | 三档文字 |
| `--vtb-line / -strong` | `--dsw-alias-border-l1 / l2` | 发丝描边、强描边 |
| `--vtb-hover / -active` | `--dsw-alias-interactive-bg-hover / active` | 交互底色 |
| `--vtb-accent` | `--dsw-alias-state-business-primary` | 焦点、链接、选中 |
| `--vtb-primary-fill / ink` | `--dsw-alias-button-primary-fill / label-primary-foreground` | 主按钮 |
| `--vtb-column` | `墨色 3% + 页面底色`（明亮 ≈ `#f8f8f8`） | 列底色，不透明，吸顶分组头复用 |

### 2.2 语义色（自持，只有这五个）

| 语义 | 浅色 | 深色 | 出现位置 |
| --- | --- | --- | --- |
| 紧急 / 失败 | `#d44c47` | `#e0736e` | 紧急度标签、失败徽标 |
| 定时 | `#d9730d` | `#e08a3c` | 计划时间徽标 |
| 成功 / 完成 | `#0f7b6c` | `#4dab9a` | 结果徽标、已完成 |
| 待验收 / 会话 | `#8e4ec6` | `#9a78cf` | 状态标签、会话跳转 |
| 人工等待 | `#cb912f` | `#d9a94a` | 等待人工条带 |

软底一律是 `color-mix(语义色 12%, transparent)`，不另存一套浅色值。

### 2.3 排版与形状

| 角色 | 值 |
| --- | --- |
| 看板标题 | 15px / 600 / `-0.01em` |
| 卡片标题 | 13px / 500 / 行高 1.45 |
| 控件与按钮 | 12.5px / 500，高 28px |
| 元数据 | 11–11.5px / 400 |
| 徽标 | 10.5px / 500，圆角 5px |
| 圆角 | 控件 6 / 卡片与内嵌块 8 / 列 12 / 弹窗 14 |
| 阴影 | 卡片无阴影（只有描边）；下拉与弹窗用 `shadow-1/2/3` |
| 动效 | 120ms，`cubic-bezier(.2,.7,.3,1)` |

## 3. 组件判据

- **列**：极浅灰卡片（`--vtb-column`）+ 12px 圆角 + 8px 内边距；列头只有「名称 + 数量」，
  **没有状态圆点**；收起态保留竖排名称与展开按钮。
- **卡片**：页面唯一的白色表面，4% 描边、8px 圆角、无阴影；hover 只加深描边并抬升 1px。
  **没有紧急度色条**——紧急度只由标签表达。
- **标签**：软底填充 + 同色文字；紧急度里只有「紧急」着色，一般/不急为中性（一般叠实心灰点，
  不急叠空心灰点，形状也参与区分）。
- **动作**：`完成 / 退回` 是墨色描边按钮（描边为墨色 22% 透明，不是纯黑），透明底；
  hover 加深描边并加浅底。与「软底标签」形成两种可区分的形态。
- **工具栏**：两行——身份行（标题 / 计数 / 更多 / 新建任务，**主操作固定在最右**）与筛选行
  （搜索 / 项目 / 排序 / 紧急度 / 待我处理 / 其它任务）。**不显示版本号**。
- **项目分组头**：吸顶，底色与列同值（不透明），卡片滑过不透字。
- **弹窗**：白底、14px 圆角、分层阴影、浅底操作区；头部图标 + 标题 + 说明。
- **图标**：Lucide 几何、1.7 描边、默认 14px；emoji 不作为图标（`✓ ✗ •` 等排版符号除外）。

## 4. 与上游的差异

| 维度 | 上游 dsh-taskboard 0.10.0 | 本插件 |
| --- | --- | --- |
| 色彩 | 跟随宿主 + 大量硬编码状态色 | 宿主令牌 + 五个语义色 |
| 图标 | emoji | 线性图标集（`src/client/icons.tsx`） |
| 工具栏 | 11 个控件平铺，主操作在左，显示版本 | 两行分组，主操作最右，无版本 |
| 列头 | 状态圆点 + 名称 | 只有名称 + 数量 |
| 卡片 | 灰底 + 边框 + 紧急度色条 | 白卡 + 4% 描边；紧急度交给标签 |
| 动作按钮 | 绿色/橙色填充 | 墨色描边 |

功能面与上游 1:1 对齐（工具、调度、worktree 隔离、模板、i18n、外部同步均保留）。

## 5. 验证

1. `npx tsc --noEmit`：类型与 i18n 键集合对齐。
2. `npx vitest run`：717 条用例（含样式契约与可访问性断言）。
3. 隔离实例截图：`DSH_HOME=<临时目录> dsh --profile web --port <port>`，亮/暗两套主题；
   用 `document.body.setAttribute('data-ds-dark-theme','')` 切换深色。
4. 检查项：五列在 1000px 面板内铺满、控件文字不被裁切、按钮不折行、卡片信息不重叠、
   正文对比度 ≥ 4.5:1。
