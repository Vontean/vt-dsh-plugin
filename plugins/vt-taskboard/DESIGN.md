# DESIGN.md — dsh-vt-taskboard 视觉体系

> 状态：**已落地**（1.0.0）。本文是看板界面唯一的视觉约定；实现值在
> `src/client/styles.ts` 顶部的 `--vtb-*` 令牌层，本文解释语义与判据，不复制数值维护第二套定义。
> 截图证据：`.preview/*.png`（本地验收用，不入库）。

---

## 1. 设计意图

| 项 | 判断 |
| --- | --- |
| 用户场景 | 用户每天盯盘：几十张卡在五列之间流转，读的是标题、状态、交付证据 |
| 界面寿命 | 长期常驻面板，不是一次性回答；同一批卡片会被反复扫视 |
| 视觉基调 | **柔和纸张**：暖白纸面、白卡、发丝描边，安静但不寡淡 |
| 信息重心 | 标题 > 状态/进度 > 交付证据 > 次要元数据；装饰一律退让 |
| 成功判据 | 3 秒内能回答「哪张卡卡住了、哪张等我验收」，且长时间看不累 |

三条铁律：

1. **一屏只有一个强调层**：主操作是唯一深色块；其余靠层级与留白区分，不靠更多颜色。
2. **颜色只来自令牌**：`--vtb-*` 之外不出现字面色值（第三方协议色除外，见 §3）。
3. **状态色永远配形状**：色点 + 文字 + 位置三重编码，色弱用户也能读。

## 2. 令牌

作用域挂在面板根、弹窗遮罩、灯箱与斜杠浮层上；深色只覆盖令牌值，不重写组件规则。

### 2.1 颜色（浅色）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--vtb-paper` | `#fbfaf8` | 看板底色（暖白纸面） |
| `--vtb-paper-2` | `#f2f1ed` | 列底色、分组头吸顶底色 |
| `--vtb-surface` | `#ffffff` | 卡片、弹窗、输入框 |
| `--vtb-surface-2` | `#f6f5f2` | 内嵌块（评论、执行记录、设置侧栏） |
| `--vtb-ink` | `#37352f` | 主文字、主按钮底色 |
| `--vtb-ink-2` | `#6b6a66` | 次要文字、按钮文字 |
| `--vtb-ink-3` | `#9a9995` | 元数据、占位符、图标 |
| `--vtb-line` | `rgba(55,53,47,.10)` | 发丝描边 |
| `--vtb-line-strong` | `rgba(55,53,47,.20)` | hover 描边 |
| `--vtb-accent` | `#2383e2` | 焦点、链接、进行中/待办状态 |

深色对应 `#1c1c1b / #242423 / #2a2a29 / #212120 / #e9e9e7 / #9b9a97 / #6f6e69`，
强调色 `#529cca`。深色卡片比列更亮，保持「纸面在下、卡片在上」的层级。

### 2.2 状态与紧急度（协议色，两个主题各自微调）

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 待规划 / 已取消 / 已归档 | `#9a9995` | `#6f6e69` |
| 待办 | `#2383e2` | `#529cca` |
| 进行中 | `#d9730d` | `#e08a3c` |
| 待验收 | `#6940a5` | `#9a78cf` |
| 已完成 | `#0f7b6c` | `#4dab9a` |
| 紧急 / 删除 | `#d44c47` | `#e0736e` |

紧急度复用同一套：紧急=红、一般=紫、不急=蓝（与上游协议一致，不重新发明语义）。

### 2.3 排版

| 角色 | 字号 / 字重 | 备注 |
| --- | --- | --- |
| 看板标题 | 15 / 600 | 字距 `-0.01em` |
| 卡片标题 | 13 / 500 | 行高 1.45，最多三行自然换行 |
| 正文 | 13 / 400 | 行高 1.6 |
| 按钮 / 控件 | 12.5 / 500 | 与 28px 控件高度成套 |
| 次要信息 | 11.5 / 400 | 元数据、提示 |
| 徽标 / 微文案 | 10.5–11 / 500 | 胶囊与角标 |
| 分节标签 | 10.5 / 600 | 全大写 + `.06em` 字距（仅用于弹窗分节） |

字体栈：`ui-sans-serif, -apple-system, "PingFang SC", "Microsoft YaHei", ...`；
代码/路径：`ui-monospace, SFMono-Regular, Menlo, Consolas`。数字一律 `tabular-nums`。

### 2.4 形状与动效

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--vtb-radius-sm` | 6px | 按钮、输入、徽标 |
| `--vtb-radius` | 8px | 内嵌块、评论气泡 |
| `--vtb-radius-lg` | 12px | 列、卡片容器 |
| `--vtb-radius-xl` | 14px | 弹窗、详情面板 |
| `--vtb-shadow-1` | `0 1px 2px rgba(15,15,15,.04)` | 卡片静置 |
| `--vtb-shadow-2` | `0 3px 10px …` | 卡片 hover、下拉菜单 |
| `--vtb-shadow-3` | `0 18px 50px …` | 弹窗、提示 |
| `--vtb-dur` / `--vtb-ease` | 120ms / `cubic-bezier(.2,.7,.3,1)` | 全部过渡 |

动效只用于「确认操作对象」：卡片 hover 抬起 1px、下拉淡入上浮 8px、弹窗淡入 0.985 缩放。
不做循环动画（唯一例外：运行中执行点的呼吸指示，表达真实进行中）。

## 3. 组件判据

- **列**：底色 `paper-2`、无描边；列头 = 状态色点 + 名称 + 数量胶囊 + 折叠按钮。
  项目分组头吸顶且底色**不透明**（`paper-2` 实色），卡片滑过不透字。
- **卡片**：白底 + 发丝描边 + 1px 阴影；左侧 3px 紧急度竖条（`inset 6px`）。
  hover 抬升一次，不做缩放。拖动经过列时用「强调色虚线内描边 + 8% 强调底」。
- **状态徽标**：软色底 + 同色文字，不用描边；语义靠色 + 文案双编码。
- **交付概览**（待验收/已完成卡片内）：图标承担标签语义，数值本身已含单位，不再重复写「3 files」。
- **人工等待**：卡片内独立黄色条带，最多两行，标题在条带上方保持可扫读。
- **工具栏**：两行结构——身份行（标题/计数/新建/更多/版本）与筛选行（搜索/项目/排序/紧急度/待办筛选）。
  窄于 1180px 隐藏版本徽标，把空间让给筛选。
- **弹窗**：白底、14px 圆角、头部图标 + 标题 + 说明、底部浅底操作区；
  遮罩 `rgba(15,15,14,.42)` + 3px 模糊，不做发光。
- **图标**：统一 Lucide 几何、1.7 描边、14px 默认尺寸；文字按钮的图标在左，外部跳转图标在右。
  emoji 不作为界面图标使用（`✓ ✗ •` 这类排版符号允许出现在正文）。

## 4. 与上游的差异

| 维度 | 上游 dsh-taskboard 0.10.0 | 本插件 |
| --- | --- | --- |
| 色彩 | 跟随宿主 `--dsw-*`，大量硬编码 `#e5484d/#8e4ec6/#3e63dd` | 自建 `--vtb-*` 纸张令牌 + 深色覆盖 |
| 字体 | 继承宿主 | 显式字体栈与六档字号 |
| 图标 | emoji（🛠 ⚙ ⬆ ⬇ ＋ ⚡ ☑ …） | 线性图标集（`src/client/icons.tsx`） |
| 工具栏 | 11 个控件平铺一行 | 身份行 + 筛选行，低频操作收进「更多」 |
| 卡片 | 灰底 + 边框 | 白卡 + 发丝描边 + hover 抬升，交付概览压缩 |
| 弹窗 | 16px 圆角、重阴影 | 14px 圆角、分层阴影、浅底操作区 |

功能面与上游 1:1 对齐（工具、调度、worktree 隔离、模板、i18n、外部同步均保留）。

## 5. 验证

1. `npx tsc --noEmit`：类型与 i18n 键集合对齐。
2. `npx vitest run`：717 条用例（含样式契约与可访问性断言）。
3. 隔离实例截图：`DSH_HOME=<临时目录> dsh --profile web --port <port>`，检查亮/暗两套主题下的
   看板、详情、任务表单、设置、导入。
4. 检查项：控件文字不被裁切、按钮不折行、卡片信息不重叠、对比度 ≥ 4.5:1（正文）。
