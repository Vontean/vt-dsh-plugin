# dsh-mcx-prompt-preset

把 **MineCodex（MCX）** 的提示词库接进 DeepSeek Harness（DSH）：

- **输入框按钮**：在「+」与审查模式之间多一个书本图标的提示词按钮，视觉与交互同「+」完全一致；
- **浮层选择**：点击后在上方弹出提示词浮层，按分类浏览、搜索，点一下就填入当前草稿；
- **提示词库页面**：侧边栏注册「提示词库」，提供浏览、搜索、新建、编辑、删除、排序、视图切换与分类管理。

数据直接读写本机 MCX 的提示词库，**不复制、不同步**，两边永远是同一份。

## 数据来源

默认读取：

```
~/Library/Application Support/CodexNotes/codex-notes.sqlite
```

Windows 为 `%APPDATA%\CodexNotes\codex-notes.sqlite`。可用环境变量 `MCX_PROMPT_DB` 指向其他库文件。

写入沿用 MCX 自己的事务语义（`BEGIN IMMEDIATE` + `metadata.revision` 自增），因此 MCX 与 DSH 同时打开也不会互相覆盖，修订号始终一致。插件只碰 `prompts` / `prompt_categories` / `metadata` 三张表，不读写历史 `todos` / `files`；库文件不存在时不会创建或建表。

## 前置条件

本机至少用过一次 MineCodex 的提示词功能，使得上面的库文件已经存在。否则浮层与页面会显示「还没有找到提示词库」，而不是报错。

## 安装

在 DSH 里用插件管理器安装该 bundle（profile 级），或在市场里安装。安装后**新开一个窗口或重载页面**让客户端模块生效。

## 交互

### 输入框浮层

| 操作 | 结果 |
| --- | --- |
| 点击书本按钮 | 打开/关闭浮层 |
| 点击提示词 | 正文追加进当前草稿，浮层关闭，并记一次使用 |
| `↑` / `↓` | 在结果之间移动焦点 |
| `Esc` | 关闭浮层 |
| 「管理」 | 切到侧边栏的提示词库页面 |

浮层内容与 MCX 一致：分类页签 → 「最近使用」→ 各分类 → 「其他」。

### 提示词库页面

- 分类页签、搜索、排序（最近使用 / 创建时间 / 标题）、列表/卡片视图切换；
- 新建 / 编辑 / 删除提示词；
- 分类管理：名称、图标（26 个 Phosphor 图标）、颜色（8 色）、删除；
- 点击条目复制正文到剪贴板。

## 设计说明

按钮不复制「+」的类名，而是**运行时读取它的计算结果**（底色、圆角、尺寸、图标尺寸、描边粗细），再用同一套 token 落成 CSS 变量。因此：

- 装了 UI Enhancer（把「+」改成透明底 + hover 才出底）时，两者一起变；
- 没装时，两者一起回到 DSH 原生的实心圆底。

细节见 [DESIGN.md](./DESIGN.md)。

## 已知限制

- 输入框按钮通过 DOM 注入实现。DSH 若调整输入框工具行的结构，按钮会退化为「读取 `_tools` 类后缀」的兜底路径；两条路径都失效时按钮不出现，页面与数据不受影响。
- 提示词库页面里的「点击」是复制，不是填入：主面板会替换对话区，此时没有可写入的草稿。需要填入时请用输入框浮层。
