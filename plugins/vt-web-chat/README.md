# dsh-vt-web-chat · 网页对话

在 DSH 桌面版的「新会话」正下方加一行「网页对话」入口，点开后在主内容区整页显示
`chat.deepseek.com`，用官网自己的对话历史，并记住上次停留的对话。

## 它改了什么

- 侧栏「新会话」下面多一行「网页对话」，点击后在主内容区打开整页网页对话；
- 载体是桌面壳的 guest 租约桥（Electron `<webview>`）。官网返回
  `frame-ancestors 'none'`，普通 iframe 无法承载，租约是主进程唯一放行的建法；
- 离开面板会释放 guest，回来时按本机记录的上次对话地址恢复；
- 纯 Web 环境（没有桌面桥）显示说明卡，并可「在浏览器打开」；
- 入口文案与面板文案随宿主语言切换（zh / en）。

## 已知限制

- **登录不共享**：内嵌页是独立 cookie 分区，无法使用 DSH 的账号凭证。可以直接在页面里
  登录，但分区是进程级的，**重启 DSH 后需要重新登录**。
- 离开面板会销毁页面内存（未发送的草稿会丢），只恢复上次对话地址。
- 桌面壳统一拒绝下载、权限请求与原生弹窗；依赖这些能力的站点功能不可用。
- 不修改「新会话」按钮：该按钮由内置侧栏直接绘制，没有插件插槽。

## 安装

1. **插件市场（推荐）**：在「插件 → 发现 → 添加索引源」里填入
   `https://vontean.github.io/vt-dsh-plugin/index.json`，找到「网页对话」点安装。
2. **npm**：`dsh plugin --profile <profile> add dsh-vt-web-chat@1.0.0`。
3. **Release tarball**：从 GitHub Release 下载 `.tgz`，再执行
   `dsh plugin --profile <profile> add <该 .tgz 的本地路径或 URL>`。

安装或升级后需要重启 DSH；只刷新页面不生效。

## 支持的 DSH 版本

`engines.dsh` = `>=0.2.1-rc.5 <0.3.0`。超出范围时，加载器会在插件装载前拒绝，
不会出现「装上了但只加载一半」的状态。

## 安全边界

- 插件代码在用户进程内运行，**没有沙箱**；只安装你信任的来源。
- 插件只增加一个界面入口：不注册 Host 服务、工具、提示词段落或路由。内嵌页面属于
  用户侧展示状态，不会进入模型请求。
- 内嵌页面的网络访问由页面自身完成，与 DSH 的模型请求链路相互独立。

## 开发

- `index.js`：Host 半侧，空实现；客户端 bundle 通过这个 Loader 入口被发现。
- `client.js`：全部功能在客户端。模块 id、`PLUGIN_ID`、`VERSION`、日志前缀与存储 key
  都从同一处常量派生，改包名时只需改 `PLUGIN_ID`。
- 本目录没有额外的设计 / 开发文档；行为说明见本文件与 `client.js` 头部注释。
